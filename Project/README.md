# Sword of Destiny (ดาบแห่งโชคชะตา)

Sword of Destiny เป็นแอปพลิเคชันทำนายดวงรายวันบน Android ที่นำระบบ Gacha มาประยุกต์ใช้เพื่อสร้างประสบการณ์ที่สนุกสนานและน่าตื่นเต้น ผู้ใช้จะได้สวมบทบาทเป็นผู้กล้าที่ต้องพยายามดึง "ดาบเอ็กซ์คาลิเบอร์" ออกจากหินเพื่อรับคำทำนายในแต่ละวัน

## ฟีเจอร์หลัก
*   **The Ritual (การดึงดาบ):** ผู้ใช้ต้องกดที่ดาบซ้ำๆ เพื่อให้ดาบหลุดจากหิน สร้างความรู้สึกลุ้นระทึก
*   **Fortune Cards:** ระบบการ์ดทำนายดวง 10 รูปแบบ แบ่งตามระดับความหายาก:
    *   Legendary
    *   Great Luck
    *   Normal Luck
    *   Bad Luck
*   **Dynamic Rates & Pity System:** ระบบปรับเปลี่ยนอัตราสุ่มตามจำนวนครั้งที่ดึงดาบ มีระบบการันตี (Pity) เพื่อให้ผู้ใช้ได้รับคำทำนายที่ดีเมื่อพยายามดึงดาบหลายครั้ง
*   **Collection History:** บันทึกประวัติการดึงดาบ พร้อมสถิติ "ความพยายาม" (Pull Count) และวันที่ได้รับการ์ด
*   **Daily Mode & Infinite Mode:** ระบบดึงดาบได้วันละครั้งเพื่อสร้างนิสัยการกลับมาใช้งานทุกวัน พร้อมตัวเลือกปลดล็อก Infinite Mode สำหรับดึงดาบแบบไม่จำกัด

## เทคโนโลยีที่ใช้
*   **ภาษาโปรแกรม:** Kotlin
*   **UI Framework:** Jetpack Compose
*   **สถาปัตยกรรม:** MVVM (Model-View-ViewModel) แนะนำ
*   **Navigation:** Jetpack Compose Navigation

## โครงสร้างโปรเจกต์
*   โปรเจกต์ถูกพัฒนาบน **Android Studio**
*   Target SDK: 36
*   Minimum SDK: 24

## วิธีการรันโปรเจกต์
1. Clone หรือดาวน์โหลดโปรเจกต์นี้
2. เปิดโปรเจกต์ด้วย **Android Studio**
3. รอให้ Gradle ทำการ Sync จนเสร็จสมบูรณ์
4. เลือก Emulator หรืออุปกรณ์จริง แล้วกดปุ่ม **Run (Shift + F10)** เพื่อเริ่มการทำงานของแอปพลิเคชัน

## กลุ่มเป้าหมาย
*   คนวัยทำงานและนักเรียน/นักศึกษา ที่ชอบดูดวงรายวัน
*   ผู้ที่ชื่นชอบเกมแนว RPG หรือระบบสุ่ม (Gacha)
*   ผู้ที่มองหาแอปพลิเคชันที่ช่วยสร้างความบันเทิงสั้นๆ ในแต่ละวัน
